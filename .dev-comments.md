# 🛠️ Guía de Configuración: Comentarios Inteligentes

Este proyecto utiliza un sistema de comentarios categorizados para mejorar la legibilidad y el seguimiento de tareas. Sigue estos pasos para configurar tu VS Code y que todo el código se vea correctamente resaltado.

---

## 1. Instalación de Extensiones 🔌

Es necesario tener instaladas las siguientes extensiones en VS Code:

1. **Better Comments** (de Aaron Bond) - Para activar los colores en los comentarios.
2. **Todo Tree** (de Gruntfuggly) - Para tener un panel con la lista de tareas.

---

## 2. Configuración del Editor ⚙️

Para que los colores y el rastreo funcionen, debemos editar el archivo `settings.json` de VS Code:

1. Presiona `Ctrl + Shift + P` (o `Cmd + Shift + P` en Mac).
2. Escribe **"Open User Settings (JSON)"** y presiona `Enter`.
3. Pega el siguiente bloque de código dentro de las llaves principales `{ ... }`:

```json
  "better-comments.tags": [
    { "tag": "!TODO", "color": "#FF8C00", "bold": true },
    { "tag": "!FIXME", "color": "#FF0000", "bold": true },
    { "tag": "!WARNING", "color": "#FFCC00", "bold": true },
    { "tag": "!INFO", "color": "#00BFFF", "bold": true },
    { "tag": "!NOTE", "color": "#20B2AA", "bold": true },
    { "tag": "!STUB", "color": "#9932CC", "bold": true },
    { "tag": "!DEPRECATED", "color": "#A52A2A", "strikethrough": true, "italic": true },
    { "tag": "!OPTIMIZE", "color": "#ADFF2F", "bold": true },
    { "tag": "!QUESTION", "color": "#FF69B4", "bold": true },
    { "tag": "!TEST", "color": "#FF1493", "bold": true },
    { "tag": "!REFACTOR", "color": "#00CED1", "bold": true },
    { "tag": "!SECURITY", "color": "#FFFFFF", "backgroundColor": "#8B0000", "bold": true },
    { "tag": "!BUG", "color": "#32CD32", "bold": true },
    { "tag": "!IDEA", "color": "#E5E619", "bold": true },
    { "tag": "!", "color": "#FF2D00", "bold": true }
  ],
  "todo-tree.general.tags": [
    "!TODO", "!FIXME", "!WARNING", "!INFO", "!NOTE", "!STUB",
    "!DEPRECATED", "!OPTIMIZE", "!QUESTION", "!TEST", "!REFACTOR",
    "!SECURITY", "!BUG", "!IDEA", "!"
  ]
```

**Importante:** Una vez guardado el archivo JSON, reinicia VS Code para asegurar que todos los colores se carguen.

---

## 3. Glosario de Etiquetas 🏷️

Usa estos prefijos después de las barras de comentario (ejemplo: `//!TODO mensaje`) para categorizar tus notas:

| Etiqueta      | Color             | Propósito / Significado                                  |
| ------------- | ----------------- | -------------------------------------------------------- |
| //!TODO       | 🟠 Naranja        | Tareas pendientes por implementar.                       |
| //!FIXME      | 🔴 Rojo           | Código que no funciona bien y debe repararse.            |
| //!WARNING    | 🟡 Amarillo       | Lógica sensible, efectos secundarios o riesgos.          |
| //!INFO       | 🔵 Azul           | Datos necesarios para entender el flujo o configuración. |
| //!NOTE       | 🟢 Turquesa       | Recordatorios sobre el estado actual del código.         |
| //!STUB       | 🟣 Púrpura        | Código temporal o de relleno (Mocks).                    |
| //!DEPRECATED | 🟤 Marrón         | Código obsoleto que será eliminado pronto.               |
| //!OPTIMIZE   | 🍏 Lima           | Código funcional pero lento o ineficiente.               |
| //!QUESTION   | 🌸 Rosa           | Dudas para investigar o consultar con el equipo.         |
| //!TEST       | 🌺 Fucsia         | Casos de prueba, mocks o asserts manuales.               |
| //!REFACTOR   | 💎 Cian           | Necesita limpieza de arquitectura (Clean Code).          |
| //!SECURITY   | 🩸 Rojo Oscuro    | Puntos críticos: Inyección SQL, Tokens, Auth.            |
| //!BUG        | 🌿 Verde          | Error reportado con descripción o ID de ticket.          |
| //!IDEA       | 💡 Amarillo       | Pensamientos para futuras versiones o mejoras.           |
| //!🔥         | 🔥 Rojo Brillante | Alerta general de alta prioridad.                        |

---

## 4. Cómo navegar el código 🚀

### 🔍 Búsqueda Global

Si quieres ver todas las ocurrencias de una etiqueta en el proyecto:

- Presiona `Ctrl + Shift + F`
- Busca el tag completo (ej: `//!FIXME`)

---

### 🌳 Panel de Todo Tree

1. Haz clic en el icono del Árbol en la barra lateral izquierda de VS Code.
2. Se desplegará una lista organizada por archivos con todos los comentarios detectados.
3. Puedes filtrar o agrupar los comentarios usando los iconos en la parte superior del panel (embudo) para enfocarte solo en lo que necesitas resolver ahora.
